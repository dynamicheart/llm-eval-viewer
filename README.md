# LLM Eval Viewer

[中文文档](README.zh-CN.md)

> This project was built entirely with AI assistance (Claude Opus 4.6).

**LLM Eval Viewer** is a lightweight web tool for **visualizing LLM evaluation results**.  
Currently supports result formats generated by **evalscope** and **MEval**.

**Live Demo:**  
https://dynamicheart.github.io/llm-eval-viewer/

---

## Features

- **Multi-view support**: Predictions, Reviews, and MEval sample viewer
- **Directory browsing**: Select a directory to auto-scan its structure, quickly switch between experiments and datasets (Chrome/Edge)
- **Dark mode**: Light / Dark / Auto theme with system preference detection
- **Token distribution**: Histogram charts with average prompt/completion token statistics
- **Result distribution**: Interactive distribution charts with click-to-filter
- **Dataset statistics**: Per-dataset accuracy, token averages, and finish reason summary; click to filter the main table
- **Hover preview**: Hover on truncated text cells to preview content; click to view full detail
- **Sticky headers**: Frozen table headers for easy browsing of large datasets
- **Reasoning support**: Displays reasoning content marked as [R], view Text and Reasoning separately
- **cURL export**: Generate cURL commands from request details for quick API replay
- **i18n**: English and Chinese language support
- **Sample data**: First-time users can load built-in sample data to explore features instantly
