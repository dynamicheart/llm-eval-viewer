# Roadmap

## v2.0

### 服务端部署模式

- 支持从 URL 拉取评测日志，无需手动上传文件
- 可配置日志源地址，定时刷新
- 适配 Docker / Nginx 等部署方式

### 可嵌入组件

- 将核心视图封装为独立 Web Component 或 Vue 插件
- 其它项目通过 `<eval-viewer src="..." />` 或 JS API 嵌入
- 支持自定义主题、字段映射

### 多模型对比

- 同一数据集下多个模型结果并排展示
- 逐样本 diff：高亮两个模型回答的差异
- 汇总对比：准确率、Token 用量等指标对比图表

### 自定义格式支持

- 提供解析器配置界面，用户定义字段映射规则
- 不再绑定 Evalscope 特定 schema，支持任意 JSONL 结构

### 导出与报告

- 一键导出筛选后的数据为 CSV / Excel
- 生成评测摘要报告（HTML），包含统计图表和关键样本
